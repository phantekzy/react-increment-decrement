# React Counter App

A simple React counter app with increment, decrement, and reset functionality, built using [Vite](https://vitejs.dev/).  
This project is a beginner-friendly example to practice React hooks and state management.

---

## Features
- Increment counter
- Decrement counter
- Reset counter
- Dynamic counter color: green for positive, red for negative

---

## Technologies Used
- **React** (JSX)
- **Vite** (build tool)
- **JavaScript**
- **HTML**
- **CSS-in-JS** (inline styles)


---

## Usage
- Click **"+"** to increment the counter.
- Click **"-"** to decrement the counter.
- Click **"RESET"** to set the counter back to zero.
- Counter text changes color based on the value.
